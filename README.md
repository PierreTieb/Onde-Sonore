# Les Ondes Sonores

Appli web (pensée pour smartphone) pour comprendre la propagation du son.

- `index.html` : page d'entrée, à la racine
- `css/style.css` : styles
- `js/` : `utils`, `sound`, `sprites`, `backgrounds`, `lab` (scène), `guided` (mode 1 guidé), `measure` (mode 2), `app` (navigation)
- `img/` : `petard.png`, `astronaute.png`. `fille.png`, `plongeur.png`, `mineur.png` (PNG à fond transparent, pieds en bas). Sans ces fichiers, des dessins intégrés sont utilisés.

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages (branche `main`, dossier racine).
